Grimling is a Claude Code mod that docks a pane of pixel-art agent cards next to your conversation. Pick one, type the task, press Enter. Watch it work, message it, read its answer.

What it does

One pane for every agent you run.

Subagents are powerful but easy to lose track of. Grimling gives each one a face, a status and a place to talk to it, without leaving the terminal.

The Grimoire

A filterable grid of agent cards: the built-in agents plus every agent file in your user and project folders. Agents without art get a generated creature of their own.

Launch in one line

Choose a card, type the task in the summon box and press Enter. If the launch is refused, your task stays in the box to try again.

Live agent cards

Running agents get their own cards. Send a message to one mid-task, or open a finished one to read its answer and add it to your prompt.

Usage meter

Your status line as bars: context used, plan limits with reset times, session cost and model.

Flow, Table and Mermaid

See who spawned whom as a flow, scan every run as a table, or copy the agent graph to your clipboard as a Mermaid diagram.

Arena

Pit two agent cards against the same puzzle. The correct answer wins, with speed and then token count as tie-breakers. Each card keeps its own win/loss rating.

Getting in and out

Grimling sits beside the chat. The keyboard belongs to either the prompt or the pane, never both.

  • /grimling opens the pane and gives it the keyboard.
  • ctrl+x then Tab moves the keyboard from the prompt into the pane. Clicking the pane works too.
  • Tab, ↓ and → move forward. Shift+Tab, ↑ and ← move back.
  • Esc hands the keyboard back to the prompt.

Typing is safe. While a text box has the focus ring, letters and digits only type. Tab letters and card numbers work again once you Tab out.

Launching an agent

  1. Move onto a card with Tab or the arrows. Its entry shows: number, category, agent type and what it is for.
  2. Press Enter on the card, or its number 1 to 9. It becomes the launch target and the cursor jumps to the summon box.
  3. Type the task and press Enter. The agent starts and gets a live card.

You can also Tab straight to the summon box and type: it launches the current target. If the launch is refused, the task stays in the box.

Template cards are different. Swarm (and any template you enable) never launches anything. It adds a request after your prompt draft so you and the main session decide what runs. Press Esc, then Enter to send it.

The Grimoire

The deck holds three kinds of card.

  • Built-ins: Scout (search the code), Builder (multi-step tasks), Planner (design a plan), Fetcher (read a URL), Guide (Claude Code and API answers), and the Swarm template card.
  • Your agent files: every agent in ~/.claude/agents and in the project's .claude/agents. A project file wins over a user file of the same name.
  • Pack agents: agent packs you list in cards.packs, shown as <pack>:<name>. Grimling ships no pack of its own yet; more packs later.

Filter by category with the chips (All, Code, Research, Web, Ops, Swarm, Custom) or press / to filter by name. Card art, short names and categories can be set in ~/.claude/grimling/dex.json.

Recent runs sit under the agents when there is room: your last six distinct launches. Press Enter on one to put its task and agent back in the summon box.

Live agents

  • Enter on a running agent opens a message box. Type, then Enter sends it to that agent.
  • Enter on a finished agent shows its answer. Enter again adds it after your prompt draft, c copies it, x closes it.
  • Answers over 8,000 characters are cut and marked "truncated". If the prompt cannot take the answer, a toast says so and the view stays open.
  • An agent that disappears without a final status shows as gone after about 10 seconds.

x or STOP on a running agent the deck launched opens a Stop / Keep confirm, with Keep under the ring. Grimling stops an agent only when you confirm, and Claude Code's permission check may ask too.

A toast appears when an agent finishes, fails or is stopped, and the status line counts running agents and failures.

The meter

Under the tabs on every view. It mirrors your status line as bars.

  • ctx: context window used, in tokens.
  • 5h and 7d: plan limits, with their reset time.
  • Session cost, session time and model (and a session count, if you point meter.sessionsFile at one).

Bars are green, turn yellow from 60% and red from 85%.

Arena

A small proving ground for your cards. Press a or use the Arena button on the bottom row.

  1. Pick a Red and a Blue fighter with ‹ and ›.
  2. Pick a puzzle. Each one has a known answer.
  3. Press Enter on FIGHT. Both fighters run on the same small model (haiku by default).

The correct answer wins. If both are correct, the faster wins; if their times are close, fewer tokens wins; if that ties too, it is a draw. Health bars move only once a fight is scored. Wins, losses and a rating per card are kept in ~/.claude/grimling/arena.json. CLEAR resets a result or a stuck fight. After a scored fight, s copies a small results card to share.

Early scaffold. Puzzles and tie-breaks are still being tuned, so expect more draws than you would like.

Collecting agent types

Every launch, answer, stop and scored fight is logged on your computer in ~/.claude/grimling/runs/, one file a day, redacted by default (log.runs: redacted, full, meta or off). Ask Claude to "collect agent types" and the bundled agent-dex skill reads that log, proposes specialized agents with a card and sprite, and saves only the ones you approve.

Safety by design

It shows and launches. It stops only when you say so.

Grimling runs inside your Claude Code session with the same permissions you already gave it. These limits are built in.

Stops only on your confirm

The stop button opens Stop / Keep with Keep as the default, then goes through Claude Code's permission check.

No network calls

The mod makes no network calls of its own. /grimling-feedback only opens a link in your browser after showing you what it holds.

Swarms ask first

Swarm cards only fill your prompt, so large multi-agent runs and anything that costs money wait for your go.

Your files stay local

The run log (redacted by default), settings and Arena ratings are plain files in ~/.claude/grimling. Agents you launch run in your session and use your plan.

Install

One line in Claude Code.

In a Claude Code session:

/plugin install grimling --marketplace grimling-dev/grimling

Or from a terminal:

claude plugin marketplace add grimling-dev/grimlingclaude plugin install grimling@grimling

Then run /reload-plugins (or start a new session) and type /grimling. Source and issues: github.com/grimling-dev/grimling.

Requirements: Claude Code 2.1.312 or newer (tested). Mods are an early-access Claude Code feature and may change between releases. The pane wants about 44 columns. Tested on Windows and Linux; macOS is untested for now.

FAQ

Questions

Does Grimling change what my agents can do?

No. It uses the same agent types and permissions your Claude Code session already has. It only gives them a place to be seen and talked to.

Does it cost anything to run?

The pane itself costs nothing. Agents you launch use your Claude plan the same way they would from the prompt, and the meter shows how much you have used.

Can I add my own agents?

Yes. Any agent file in your user or project agents folder gets a card. Set its art, short name and category in dex.json, or let the agent-dex skill propose one.

Will it work in my terminal?

Its tests pass on Windows, Linux and macOS in CI, and it is built and used daily in Windows Terminal. Nobody has tried it live on macOS yet, so reports from Mac users are welcome: /grimling-feedback or an issue.

Is this made by Anthropic?

No. Grimling is an unofficial community mod for Claude Code, not affiliated with Anthropic.
